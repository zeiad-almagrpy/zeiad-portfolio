# Ziad Portfolio — Final React Demo

Modern black/purple responsive developer portfolio built with React + Vite.

## Run
```bash
npm install
npm run dev
```

If PowerShell blocks npm on Windows, use:
```bash
npm.cmd install
npm.cmd run dev
```

## Where to edit your links
Open `src/data.js`.

- `whatsappNumber` — international format without + or spaces.
- `whatsappMessage` — the prepared WhatsApp message.
- `email`
- `github`
- `linkedin`
- Each project has `live` and `github` fields.

The ELMAGHRPY live demo is already connected.
